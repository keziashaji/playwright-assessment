# Playwright Automation Assessment

## Setup

npm install

## Run all tests

npx playwright test

## Run single test

npx playwright test tests/login.spec.ts

## View report

npx playwright show-report

## Test Cases

- Login
- Invalid Login
- Products
- Cart
- Checkout
- Logout
- Categories
- Remove Cart
- Multiple Products
- Empty Checkout
